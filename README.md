# Окситоцин-чек — доза окситоцина за индукцию

Одностраничное веб-приложение для расчёта суммарной дозы окситоцина (Ед) при
**низкодозированной схеме** родовозбуждения: старт 1,8 мл/ч, увеличение на 1,8 мл/ч
каждые 30 минут, по достижении 4–5 схваток за 10 минут скорость сохраняется.

## Возможности

- **Раствор и схема** настраиваются: Ед в растворе и объём (по умолчанию 5 Ед в 50 мл = 0,1 Ед/мл,
  1,8 мл/ч = 3 мЕд/мин), стартовая скорость, шаг, интервал, порог предупреждения в мЕд/мин.
- **У постели (таймер)**: доза в Ед и мл считается в реальном времени; через каждый интервал —
  напоминание со звуком «пора увеличить скорость»; кнопки «4–5 схваток: держать скорость»,
  снижение на шаг, остановка/возобновление, отмена последнего действия, завершение.
  Журнал с временем и готовый текст для истории родов (копируется одной кнопкой).
- **Расчёт по времени**: выбираете скорость, на которой достигнуты 4–5 схваток, и длительность
  инфузии — получаете суммарную дозу, объём, график скорости и таблицу по интервалам.
- **Лист наблюдения в PDF** по форме отделения («Лист наблюдения при проведении индукции родов
  препаратом окситоцин»): ФИО, № ИР, дата и таблица Время / Доза / Схватки / КТГ / АД / Пульс / t / Диурез.
  Строки идут каждые 30 мин от начала инфузии; время и доза (мЕд/мин и мл/ч) заполняются автоматически, наблюдения
  (схватки, КТГ, АД, пульс, температура, диурез) вносятся в приложении и попадают в ближайшую строку. Внизу — суммарная доза.
  Свободные строки остаются для записей от руки. Из режима «Расчёт по времени» лист строится по схеме.
- **Шпаргалка по ступеням**: доза к концу каждой ступени и расход в час на каждой скорости.

Формула: доза (Ед) = Σ скорость (мл/ч) × время (ч) × концентрация (Ед/мл).

Пример: 4 ч инфузии, плато на 7,2 мл/ч → 0,09 + 0,18 + 0,27 + 1,8 = **2,34 Ед** (23,4 мл).

## Запуск

Это файл `index.html` без сборки; для PDF рядом лежит библиотека `vendor/pdfmake`
(pdfmake 0.2.20, MIT, со шрифтом Roboto с кириллицей). Открывать можно прямо с диска,
если папка `vendor` лежит рядом. При пуше в `main` workflow публикует его на GitHub Pages
(в настройках репозитория: Pages → Source: GitHub Actions).

Данные журнала и настройки хранятся только в браузере устройства (localStorage).

> Приложение — средство документирования и расчёта. Оно не заменяет клиническое решение врача
> и протокол отделения.
